\# Fidelity Quantum Kernels



Numerical investigation of the spectral structure and effective complexity of fidelity quantum kernels.



The project studies finite-sample quantum kernel Gram matrices generated by separable and entangling quantum feature maps using exact statevector simulation with Qiskit.



\## Current Experiments



\- \*\*Analytical reference validation:\*\* Numerical evaluation of separable and interleaved CNOT feature maps on a two-dimensional Cartesian product grid.

\- \*\*Entangling depth:\*\* Spectral comparisons of CNOT and CZ feature maps for depths L = 1, ..., 5, including deterministic grid inputs and 20 random input realisations.



The analysis includes numerical rank, participation-ratio effective rank, leading spectral weight, and relative low-rank approximation errors.



\## Project Structure



\- `qfk/` — Data generation, quantum circuits, fidelity kernels, and spectral diagnostics.

\- `experiments/reference\_grid.py` — Numerical reference-case validation.

\- `experiments/depth.py` — Entangling-depth experiments.

\- `results/depth/` — Numerical results and generated figures.



\## Installation



Python 3.11 or newer is required.



```bash

python -m pip install -e .

```



\## Running the Experiments



From the project root:



```bash

python -m experiments.reference\_grid

python -m experiments.depth

```



The experiment scripts can also be executed directly in a Python IDE after installing the package.
